# 📇 Address Book - 通讯录管理系统

一个基于 Java Swing 开发的桌面通讯录管理程序，提供联系人增删改查、分组管理、回收站、重复联系人检测与合并、文件导入导出等完整功能。

---

## ✨ 功能特点

### 👤 联系人管理
- ✅ **新增联系人**：支持姓名、电话、手机、邮箱、生日、地址、所属组等完整字段
- ✅ **修改联系人**：双击表格或右键选择修改
- ✅ **删除联系人**：移至回收站（软删除），支持批量操作
- ✅ **回收站机制**：可恢复或彻底删除联系人
- ✅ **批量操作**：支持多选联系人进行批量删除、移动等

### 📂 分组管理
- ✅ **新增/删除/重命名分组**：灵活管理联系组
- ✅ **移动联系人到分组**：将联系人从一个分组移动到另一个
- ✅ **添加到分组**：将联系人添加到多个分组（一个联系人可属于多个组）
- ✅ **从分组移除**：从当前分组中移除联系人（不删除联系人本身）
- ✅ **未分组联系人**：自动显示未归组的联系人

### 🔍 搜索功能
- ✅ **姓名搜索**：支持中文名模糊搜索
- ✅ **拼音搜索**：支持姓名首字母（如 "zs" 搜索 "张三"）
- ✅ **全拼搜索**：支持完整拼音搜索
- ✅ **手机/电话搜索**：按号码快速查找
- ✅ **实时搜索**：输入关键词后点击搜索按钮或按回车键

### 🔄 重复联系人检测与合并
- ✅ **多种检测策略**：
  - 精确姓名匹配
  - 精确手机匹配
  - 模糊姓名匹配
  - 多字段综合匹配（姓名 + 手机 + 邮箱）
- ✅ **智能合并**：自动选择信息最完整的联系人作为主记录
- ✅ **批量合并**：支持合并所有重复组或逐个选择合并
- ✅ **字段智能合并**：多字段数据自动合并（如多个电话合并显示）

### 📁 文件导入导出
- ✅ **CSV 格式**：支持 Excel 可直接打开的 CSV 文件导入/导出
- ✅ **vCard 格式**：支持标准 vCard（.vcf）格式导入/导出，可与手机通讯录互通
- ✅ **批量导入**：一次性导入多个联系人
- ✅ **选择性导出**：支持导出选中的联系人，或导出全部

### 🎨 界面定制
- ✅ **自定义显示字段**：自由选择表格中显示的列（姓名、电话、邮箱、所属组等 14 个字段）
- ✅ **预设显示方案**：一键切换 "姓名+电话" 或 "姓名+电子邮箱"
- ✅ **状态栏提示**：实时显示当前视图和联系人数量

### 🔐 用户登录
- ✅ **简单登录验证**：内置账号密码验证
- ✅ **默认账号**：`2024252206` / `123456`

## 🚀 如何运行

### 方式一：通过 IDE 运行（推荐）

1. **克隆项目**
   ```bash
   git clone https://github.com/Zen-Pure/address-book.git
   
2. **导入项目**

使用 IntelliJ IDEA 或 Eclipse 打开项目

确保 JDK 8 或更高版本已配置

3. **运行程序**

找到 src/addressbook/Main.java

右键 → Run 'Main.main()'

### 方式二：命令行运行

**进入项目目录**

cd address-book

**编译所有 Java 文件**（需要 pinyin4j 库在 classpath 中）

javac -cp ".;lib/*" src/addressbook/**/*.java src/addressbook/*.java

**运行程序**

java -cp ".;src;lib/*" addressbook.Main

⚠️ 注意：本项目依赖 pinyin4j 库，请确保将其添加到项目的 classpath 中。
